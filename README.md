# COSC-386: Database Design and Implementation

This repository contains coursework and database projects completed for **COSC-386: Database Design and Implementation** at **Salisbury University**.

## Overview

This course focused on the design, implementation, and documentation of database systems. Coursework explored database structures, SQL queries, data modeling, and techniques for efficiently storing and retrieving data.

## Coursework

This repository includes:

- **Golf Course Database** – Database design and implementation project
- **In-Class Exercises** – Database exercises and SQL practice completed throughout the course

## Concepts Explored

- Relational database design
- SQL
- Database schemas
- Tables and relationships
- Primary and foreign keys
- Data modeling
- Database queries
- Data insertion and manipulation
- Query optimization
- Database implementation
- Database documentation

## Technologies

- SQL
- Relational Databases
- Database Design
